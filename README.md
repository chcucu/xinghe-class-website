# 星河班 班级网站

昆三中度假学校 八年级一班。黑白色调的 macOS 风格网站，多种艺术字体，专门为手机端做了适配。

项目地址：https://github.com/chcucu/xinghe-class-website
遇到问题可以发邮件：chenjh8557@outlook.com

## 这是什么

一个属于我们班的内部网站。同学、老师和家长登录后，可以看班级介绍、相册、新闻、积分，也可以上传照片、查看成长档案。网站是私密的，只对本班成员和家长开放。

## 怎么开始

1. 在身份选择页选你是哪一类人。
2. 本班同学和老师选"班内成员"，用账号加密码登录。
3. 家长的账号要注册，注册时选你关联的孩子，等班主任审核通过。
4. 访客也可以注册，同样要等审核。

学生初始密码是 123456，第一次登录请改成自己的密码。

## 网站有哪些功能

- 班级介绍和师生风采。看班级概况和每一位老师同学。
- 班级相册。人人都能传照片，可以新建相册、改照片名字、看是谁传的。
- 操行银行。积分分七类记分，学习、纪律、卫生、仪容仪表、考勤、综合素质、其它，按总分排名。
- 班级商店。用积分换东西，市场监督局负责审批。
- 成长档案。记录自己的进步和目标，家长登录后能看自己孩子的。
- 部门事务。宣传部、纪检部、编辑部、医疗部分工管理各栏目。
- 编辑部星河小报。每一期的电子小报放在这里，点开就能看。
- 通知公告、值日表、投票、悄悄话墙、活动接龙。
- 管理员后台。管理用户、审核注册、处理兑换，所有操作都有记录。

在手机打开也能用得顺手，菜单、相册、表格都为触屏优化过。

## 怎么自己跑起来

这个网站是纯静态的，把整个文件夹放到任意静态服务器就能用。本地预览可以运行：

```
.\serve.ps1
```

然后浏览器访问 http://localhost:5500

## 数据存在哪里

默认存在浏览器的 localStorage 里。要多人共享同一份数据，需要部署 Cloudflare Worker 后端，后端代码在 backend 文件夹里。
